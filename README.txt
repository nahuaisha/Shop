NAHU'S COLLECTION — WEBSITE FILES

Included:
- index.html: Home page
- shop.html: Shop page with product filters and Viber order buttons

Preview locally:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Open shop.html to view product listings.

Edit products:
Open shop.html in a text editor and find `const products = [`.
Edit each product's name, type ("physical" or "digital"), price, icon and description.
Prices are shown in MVR.

Viber:
The shop uses Viber's share flow with a pre-filled product message. Depending on device/browser, the customer may need to select Nahu's chat in Viber. The general contact link uses https://viber.me/9607409157.
Viber number is treated as Maldives country code +960 and number 7409157.

Free hosting:
A straightforward option is GitHub Pages. Create a GitHub account, create a public repository, upload index.html and shop.html, then enable Pages in the repository settings. The site is static and does not require a backend. A custom domain is optional and usually costs money.
